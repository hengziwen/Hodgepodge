**当前状态：构建与资产基线已建立。** 已读取 13 个相关资产并保存只读快照、源资源哈希和原字段对照；本轮结果统一归档到 Saved/ACTCombat。既有 Client 共鸣窗口故障仍保留，不因本轮受击测试通过而关闭。

约束：不把旧 DLL 的缺字段当空配置，不覆盖用户未保存资产，不自动修改伤害、窗口或判定。用户暂停的故障可以先记录，若阻塞真实输入验收则标记阻塞，不越权扩展修复。

约束：Body／Judgement 不变；不能为了更强表现绕过不能取消的能力。抑制动画不吞独立伤害、接触或阶段收益；保留整链与空中上限，不引入平行状态机。

完成标准：同级密集命中不机械重启；轻击不无意降级重反应；控制和当前姿态始终有明确对应；倒地／起身／空中不错误回到站立；取消与旧回调无资源残留。

约束：不提高伤害／攻击判定强行获得受击；不保证第二刀必然反向；不覆盖旧长动作或第三方源资源。Light／Medium／Heavy 是表现分类，尚无三套音色时如实记录。

### D：普攻、移动取消、闪避与派生样例，P0／P1，依赖 A

剩余工作：物理输入体验、既有 Client 连段故障和复杂同时输入的完整实战回归。单人五段接移动退出、方向闪避、闪避后普攻闭环已有实际输入证据；跑攻与切手明确暂缓，不作为本轮完成条件，连续闪避轮次后续按内容缺口评估。

完成标准：早按在允许缓存内可消费、过期不触发、禁止段不穿透、同时输入选择可解释；取消后旧刀无额外采样／收益；下一动作不必先跳回 Idle，拥有者与模拟代理一致。

### E：玩家受击恢复与视觉尾部，P1，依赖 A、B，和 D 对齐

输出：一组正式受击的恢复窗口配置及行为差异、接口／资源所有权说明、动作交接演示。

约束：不全局打开 bAllowWhileHitReacting，不全局取消 Montage 停止；先清理旧玩法资源，再允许尾部。客户端不得提前解除权威控制，根运动只能由一条当前有效路径驱动。

完成标准：允许的闪避／反击／移动分时生效，禁止期不能逃脱；无输入时恢复自然，有新动作时可接管；死亡、取消、换 Pawn 不残留尾部回调或旧根运动。

## 3. 测试分层与通过含义

### 3.1 文档、代码与资产

本轮已进入实现，C++ 变更按项目流程执行常规 Editor／Game 构建；反射布局变更关闭编辑器、构建后冷启动。文档检查不能代替构建，Live Coding 不替代常规构建。实际命令与结果见[10-17 验证](../Validation/act-combat-animation-feedback-2026-10-17.md)。

资产核查覆盖骨架、RootMotion、Additive 类型／基准、Slot Group、实际编译权重、通知时间、Section、Reaction 覆盖及软引用驻留。原生 Details 目视检查、蓝图编译、PIE 和艺术评价分别记录。

每个实施切片先做冷启动冒烟：默认 Experience 正常完成、正式 Hero 与目标 ASC／Profile／能力就绪，一次真实攻击产生预期伤害与反应，结束／取消后回到可行动状态，退出 PIE 无自有回调或句柄残留。冒烟通过后再做该批关键场景；它不替代完整联机或手感验收。

### 3.2 关键场景清单

每条记录预期、实际、模式／角色、证据和通过／失败／未执行，不以测试总数代替覆盖。

**命中与控制：**

- H01：正式五段完整真实输入；每个合法接触与原有实际伤害、HitGroup 限流及角色收益一致。
- H02：前、后、左、右命中；选择方向来自接触快照，目标转身和 RPC 延迟不改变原方向。
- H03：0.2 秒内两次独立命中，包含已知 0.12 秒混出重启回归；伤害／接触各两次，同级局部 Montage 不重启。
- H04：轻反馈中受到更强表现；按规则替换，较强表现本身不提升打断等级。
- H05：连续 HitStun 跨过原动画片尾；控制延长有对应持续姿态／恢复，无空等或机械回第 0 帧。
- H06：Knockback 中接轻 HitStun、HitStun 中接 Launch；符合明确转换规则，无旧 RMS 或 PendingLaunch 残留。
- H07：Downed／GettingUp 中接纯 HitStun；不站起、不错误重置计时，其他重击按独立规则裁决。
- H08：高 Body 的正式 Guardian 主动出招中接低判定；合法伤害和接触仍在，招式与运动不被非法取消。
- H09：免疫、GodMode、明确拒绝、无 Damage 输出、被接受但零生命损失及 ExplicitControl；逐分支符合各自语义，不混为跳字显示条件。
- H10：目标最后一击死亡；伤害、死亡和接触反馈责任明确，无漏播／双播，无死亡后新控制。

**动画、运动与恢复：**

- A01：FullBody 与局部 Additive 并存；主能力不中断，分骨和 Montage 权重分别观察。
- A02：击退起始、衰减与结束；位移／速度对齐动画，碰撞后不强行补偿距离。
- A03：Launch → AirHit → Landing／Knockdown → GetUp；实际落地推进，空中上限与托举次数可靠。
- A04：墙、天花板、斜坡、平台边缘、无落地超时；不穿透，不无限浮空。
- A05：玩家受击后分别早按闪避、反击和移动；缓存／开放／消费时间正确，禁止期不能穿透。
- A06：自然恢复、下一动作接管、死亡强制接管；纯视觉尾部不能继续伤害、收益、朝向或运动。
- A07：移动输入退出、急停、Pivot 与攻击后重新起步；脚位、速度和下一个动作连续。

**输入与连段：**

- C01：缓存区间内、区间外、过期及新输入替换；消费一次，不无限排队。
- C02：普攻／重输入派生／闪避／移动窗口不同步时，按当前执行与优先级选择，不消费别的动作窗口。
- C03：结束后连段记忆、移动取消、闪避后攻击和重开首刀；每条入口的记忆规则可追溯。
- C04：客户端请求被服务器拒绝、迟到请求、旧通知到达；新动作不被旧执行清理，旧执行不复活。
- C05：物理键鼠／手柄实际五段及共鸣回路前异常复现；不能以自动调用 GA 代替。

**网络、生命周期与性能：**

- N01：Standalone、Listen 主机／远端拥有者、PIE Dedicated／模拟代理分别观察；Dedicated Server 跳过音画，Listen 主机及各有渲染客户端按合法接触各播放一次，不能误禁主机反馈。
- N02：100ms 延迟、适量丢包和状态晚到；表现可降级，玩法结果不能因丢失接触事件改变。
- N03：相关性离开再进入；持续反应、姿态和运动能重建，一次性事件不伪造补伤害。

## 4. 可视化与主观验收

固定正式角色、正常／高抗目标、地图、相机、站位、伤害、Body／判定与输入；保留改动前后配置。先纯动作，再加声音与火花，再做可选镜头对照，默认无 HitStop。

优先采集含实况声音的真实 60fps 录屏，同时提供正常速度和 0.25 倍回放，记录实际采集帧率与掉帧。等价连续渲染帧可辅助检查姿态／轨迹，但要声明其采样、暂停／步进方法；不能验证音色或实时性能的部分保留缺项。

调试叠加／关联日志至少包含输入与窗口、执行身份、HitId、AttackPhase、Rank／Body、Outcome、Sequence／Phase、选中动画和替换原因、播放位置／权重、胶囊速度与接触可靠性；不以单帧 getter 冒充同帧全部事件。

由用户分别评估：接触明确、方向一致、五段连贯、击退／浮空重量、高抗反馈、恢复自然、特效可读性。目标每项至少 4／5，工程检查不代替评分；当前七项均未在本轮评分。
