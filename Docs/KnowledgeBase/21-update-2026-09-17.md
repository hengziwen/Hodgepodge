## 结论发生变化的条目

以下旧结论已过时，本轮撤销：

- **ASC 双路径已收敛**：`AHodgeHeroCharacter::PossessedBy` / `OnRep_PlayerState` 现在只调用 Super（源码内原注释未更新，属注释过期）。ASC 接入统一为 HeroComponent → PawnExtension::InitializeAbilitySystem，入口是 PawnExtension 到达 DataInitialized 之后。PlayerState::PreInitializeComponents 的 `GetPawn()` 占位首绑仍在。
- **基础 AbilitySet 授予已接通**：`AHodgePlayerState::SetPawnData` 在权威端遍历 `PawnData->AbilitySets` 调用 `GiveToAbilitySystem(ASC, nullptr)`，随后发 `NAME_HodgeAbilityReady` 并 ForceNetUpdate。**未记录 GrantedHandles**，撤销与防重仍需设计。
- **Receiver 生命周期已配对**：`AHodgeCharacterBase` PreInit 注册、BeginPlay 发 GameActorReady、EndPlay 移除 Receiver（原"EndPlay 又发 GameActorReady"的不对称已修复）。
- **额外输入移除已实现**：`UHodgeHeroComponent::RemoveAdditionalInputConfig` 按 InputConfig 解绑并移除记录；句柄持久化在 `AdditionalInputConfigHandles`；`EndPlay` 统一解绑并清空。

## 新增实现

- **攻击时间轴**：`UHodgeAbilityTimeline`（阶段/事件/Montage 软引用 + 编辑器校验 + Bundle 收集）、`UHodgeAbilityTask_PlayTimeline`（Tick 推进逻辑时间、阶段 loose tag、GameplayEvent 分派、自动 `EndTask`、`OnDestroy` 清标签、不依赖 PredictionKey）、`UHodgeComboSet`（AttackID→Timeline 节点、入口与转移、`FindNode`）。
- **Bundle 预加载**：`UHodgeAssetManager::PreloadPrimaryAssetBundles`（同步阻塞 + 保存 `FStreamableHandle`）；`UHodgeGameplayAbility::PreloadPrimaryAssetsOnGrant` 在授予时预加载 `FHodgeBundles::Equipped`。
- **攻击相关 GameplayTag**：`Attack.Entry.*` / `Attack.Transition.*` / `GameplayEvent.Attack.*` / `Status.Attack.*` / `Status.AttackMode.*` 已注册。
- **CodexText 实验模块**：ALS 风格 6 向动画（`UHodgeALSLocomotion`）、平地起停/脚锁（`UHodgeGroundedLocomotion`）及编辑器 Authoring 库、`AHodgeLocomotionLabMode`（复用 HodgeGameModeBase）、`AHodgeSurvivorHero` / `AHodgeSurvivorMode` / `UHodgeSurvivorHUD`（直接继承引擎类，绕开 Hodge GAS/Experience）。主体系无 C++ 引用。

**关键限定**：时间轴三件套是"有实现、无 C++ 调用点"——没有任何 Ability 调用 `PlayTimeline`，也没有代码调用 `ComboSet::FindNode`。因此在 BP 接线并跑 V13/V14 之前，不能声称攻击/连击可用。
