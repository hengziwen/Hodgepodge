### "待复活"机制（新增约定，重要）

依赖不满足的 UI 代码**不删除、也不用 `#if 0`**，而是**逐行加 `// ` 注释保留**，文件头放 `[UI-MIGRATION-PENDING]` 标记块说明缺什么依赖。全仓搜该标记正好 **24 个文件**：

Weapons 8 / PerformanceStats 4 / Subsystem 4 / `HodgeSettingScreen` 2 / `HodgeGameViewportClient` 2 / `HodgeConfirmationScreen` 2 / `HodgeFrontendStateComponent` 2。

复活它们需要的上游：**CommonGame**（`UGameUIManagerSubsystem` / `GameUIPolicy` / `PrimaryGameLayout` / `UCommonLocalPlayer`）、**GameSettings**、**CommonUser + ControlFlows**，以及尚不存在的 `Performance/` 与 `Weapons/Equipment/Inventory` 系统。

历史进度：30 → 26（`SActorCanvas` / `IndicatorLayer` 复活）→ **24**（本轮 `UHodgeHUDLayout` 复活）。

### HUD 换代

- `AHodgeHUDBase` **已删除**，改为 **`AHodgeHUD`**（`UCLASS(Config=Game)`）：注册 GameFrameworkComponent 接收器、广播 `NAME_GameActorReady`、把带 ASC 的 Actor 汇总进 `GetDebugActorList`；**不创建任何控件**。
- `AHodgeGameModeBase` 构造里 `HUDClass = AHodgeHUD`；`AHodgePlayerController::GetHodgeHUD()` 用 `CastChecked<AHodgeHUD>`。
- `DefaultEngine.ini` 的 `[CoreRedirects]` 新增 UI 类映射（`LyraHUD → HodgeHUD`、`LyraUIManagerSubsystem → HodgeUIManagerSubsystem` 等）。

### 依赖与插件变化

- `.uproject`：**`CommonUI` = Enabled**（新增）。
- `Build.cs` Public 新增 **`UMG` / `Slate` / `SlateCore` / `CommonUI` / `CommonInput`**；Private 新增 **`ApplicationCore`**。注意 `UMG` / `SlateCore` 原本只为 CodexText 的 UMG 用，现在进的是 Runtime 依赖。
- 未引入：CommonGame / GameSettings / CommonUser（这是 24 个文件复活不了的根因）。

### `GameFeatureAction_AddWidget` 复活

从"整文件注释"恢复为完整实现（`AddToWorld` / `AddWidgets` / `RemoveWidgets` / `Reset`，对 `AHodgeHUD` 注册扩展 Handler）。**唯一仍注释的是 `UCommonUIExtensions::PushContentToLayer_ForPlayer`**（include 与调用都注释）→ 所以 **`Layout[]` 当前不会真正创建控件**。

### 下蹲被临时屏蔽

`UHodgeHeroComponent` 里 Crouch 的 `BindNativeAction` 被注释；`Input_Crouch` 函数体、`AHodgeCombatCharacter::ToggleCrouch`、`bCanCrouch=true` 都保留。`HodgeLocomotionLab.cpp` 里另有显式 `bCanCrouch=false`。属临时处理，动画 / UI 就绪后需接回。
