## 一、技能 Definition 与连击系统（本轮主体，已验证）

这是**当前连招主链路**，取代了旧的 `UHodgeGameplayAbility_BasicAttack::AttackSteps`。

| 层 | 类型 | 职责 |
|---|---|---|
| `UHodgeAbilityDefinition` | `UPrimaryDataAsset` | **单段技能**：`AbilityTag`、`AbilityClass`（必须 `UHodgeGameplayAbility_Definition` 子类）、`ExecutionConfig{ Montage, PlayRate, BlendIn, NaturalBlendOut, StopBlendOut, TimelineTaskConfig.Timeline }` |
| `UHodgeComboDefinition` | `UPrimaryDataAsset` | **连招跳转表**：`ComboTable`（DataTable，`FHodgeComboRow` + `FHodgeComboTransition`）+ `EntryComboTag` + `InputBindings[]` + `InputBufferSeconds`（默认 0.3）+ `MoveCancelWindowTag` / `MoveIntentThreshold` |
| `UHodgeComboComponent` | `UPawnComponent` | **已挂到 `AHodgePlayerState`**（构造 `CreateDefaultSubobject`，PawnExtension 初始化时 Configure）。职责：输入单槽缓冲、按窗口 + Required/Blocked 源标签 + 优先级选边、授权 Handle、失败回 `Entry` |
| `UHodgeGameplayAbility_Definition` | `UHodgeGameplayAbility` 子类 | 执行层：反查 Definition → 要求 `Combo->IsAuthorized(Handle)` → 播 Montage + `PlayTimeline::PlayMontageTimeline` → 窗口 / 事件回调转发给 Combo |
| `UHodgeTimelineEvaluator` | 纯静态求值器 | 无时钟、无副作用，**运行时与编辑器共用**；配套 `Hodge.Timeline.SharedEvaluator` 测试 |

**ComboSet 缺口终于补上**：此前若干轮一直记着"`UHodgeComboSet` 仍不存在"（KB-15），现在由 `UHodgeComboDefinition`（DataTable 跳转表）实现，且是**已挂载、已验证**状态。

### 关键设计点

- **输入缓存**：单槽、0.3 秒、新输入覆盖旧输入；过期不再接段
- **切段前预检查**：失败保留当前动作；实际切换失败回 `Entry`
- **标签账本**：拥有端与权威端各维护本地账本，模拟代理收 `skip-owner` 快照 → 不重复计数
- **事件链上限**：单次最多处理 32 次，超过报错并清理回 `Entry`（防零时间循环）
- **网络**：输入切段沿用 GAS `LocalPredicted` 激活 RPC；**服务器按收到时的当前执行窗口重新选边**，不接受客户端指定目标，也不提供历史窗口补偿；Timeline 事件派生由权威端触发
- **时间轴时长**：支持 `Use Montage Duration`（从 Montage 派生），窗口用"源动画秒数"，不再乘 PlayRate

### 资产与验证

- 资产在 `/Game/CodexText/DefinitionCombo/`：`GA_Attack_1~5`、`DA_Attack_1~5` + 对应 Timeline、`DT_LightCombo`（六行跳转表）、`DA_LightCombo`、`AS_LightCombo`
- `DA_Dafult_PawnData` 已存 `ComboDefinition = DA_LightCombo`，AbilitySets 含 `AS_LightCombo`
- 验证 [`Docs/Validation/definition-combo-2026-09-28.md`](../Validation/definition-combo-2026-09-28.md)：Editor + Game 两目标构建退出码 0；单人 PIE **14 项**、Listen Server（拥有端 **23** / 主机 **19**）、网络模拟（750ms 延迟、10% 丢包 + 重复包）**15 项**、原生自动化 **7/7** 通过。**不含命中判定与伤害**
- 新增测试：`Hodge.Combo.DefinitionGrant` / `GraphValidation` / `SessionRules` / `MontageDuration`、`Hodge.Timeline.SharedEvaluator`

## 二、独立编辑器模块 `HodgeAbilityEditor`（可用）

`Source/HodgeAbilityEditor/`（9 个文件，`Type: Editor`，`LoadingPhase: PostEngineInit`），已在 `HodgepodgeEditor.Target.cs` 的 `ExtraModuleNames` 登记。依赖 `Hodgepodge` / `UnrealEd` / `AssetTools` / `PropertyEditor` / `Slate` / `AdvancedPreviewScene` / `AnimGraph` 等。

**入口**：内容浏览器双击 `UHodgeAbilityDefinition` 资产（模块注册了 `FHodgeAbilityDefinitionActions`）。

| 组成 | 说明 |
|---|---|
| `FHodgeAbilityEditorToolkit` | `FAssetEditorToolkit + FGCObject + FEditorUndoClient`；对外提供 `Seek` / `TickPreview` / `AddEvent` / `DeleteEvent` / `DuplicateEvent` / `TogglePlay` / `Validate` / `MakeUniqueTimeline`，带 Undo/Redo |
| 六个停靠页 | Definition / Preview / Timeline / Ability Tasks / Selected Event / Validation |
| `SHodgeAbilityPreview` | `SEditorViewport` 子类：`FAdvancedPreviewScene` + 骨骼网格 + 当前 Montage，可定位到某时刻看姿势 |
| `SHodgeAbilityTimeline` | `SLeafWidget` 自绘轨道：拖动条目、拖两端改窗口、滚轮缩放平移、键盘操作；编辑用 `FScopedTransaction` 包裹 |
| `HodgeAbilityEditorTests` | `Hodge.Editor.DefinitionWorkflow`：加载 `DA_Attack_5` 内存副本，测增删改 / 撤销重做 / Seek / 预览姿势变化 / 终点无活动窗口 |

**边界**：只支持单 Section 正向技能；不模拟 GAS 激活、命中、网络与位移。

## 三、装备系统四件套（Lyra 移植，编译通过但零挂载）

| 类 | 基类 | 职责 |
|---|---|---|
| `UHodgeEquipmentDefinition` | `UObject` | 数据：`InstanceType`、`AbilitySetsToGrant[]`、`ActorsToSpawn[]`（Actor + AttachSocket + AttachTransform） |
| `UHodgeEquipmentInstance` | `UObject`（支持复制） | 运行时实例：`SpawnEquipmentActors` / `DestroyEquipmentActors` / `OnEquipped/OnUnequipped`（转发 `K2_*`）/ Iris 复制片段 |
| `UHodgeEquipmentManagerComponent` | `UPawnComponent` | 容器：`EquipItem` / `UnequipItem`、FastArray 增量复制；`AddEntry` 授予 AbilitySet **并保存 `GrantedHandles`**，`RemoveEntry` 用 `TakeFromAbilitySystem` **精确撤销**（比 PlayerState 的 AbilitySet 授予更完整） |
| `UHodgeWeaponInstance` | `UHodgeEquipmentInstance` | 武器特有：`ApplicableDeviceProperties`（手柄震动）、`UpdateFiringTime` / 闲置时间、`OnDeathStarted` 清理 |

**未挂载证据**：没有任何 `CreateDefaultSubobject<UHodgeEquipmentManagerComponent>`；它不是 `BlueprintSpawnableComponent`（蓝图面板搜不到）；`Docs/Design/equipment-weapon-system.md` 明写"均未挂载、未建资产、未接线"。

想启用（"武器挂手"）的最小路径：① 定 ManagerComponent 挂在哪（建议 `AHodgeCombatCharacter`，Init State 初始化时把 ASC 交给它）→ ② 建 Definition 资产（`ActorsToSpawn` 填武器 Mesh + 手部 Socket）→ ③ `EquipItem(Definition)` 验证挂上 / 授予 / 撤销归零。

> 边界：装备的 UI 侧（`HodgeReticleWidgetBase` / `HodgeWeaponUserInterface`）仍在 `[UI-MIGRATION-PENDING]` 注释中；`PickBestAnimLayer` 是空壳（Cosmetics 动画层已注释），所以"武器挂上了但持握动画不对"是预期现象。
