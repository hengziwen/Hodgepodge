## 三、共鸣（Resonance）与暗涌（Havoc / Dark Surge）体系

这是本轮体量最大的新玩法，两者都是**基于既有 Melee 模板 + 动画通知**搭出来的，没有引入新战斗框架。

| 组成 | 说明 |
|---|---|
| `UHodgeResonanceSet` | 新 AttributeSet：`ResonanceEnergy` / `MaxResonanceEnergy`（**资源放在 PlayerState 的 ASC 上**，`HodgePlayerState.h:314,316`） |
| `UHodgeResonanceEnergyEffect` / `...Initialization` | 充能与初始化 GE |
| `UHodgeAbilityCost_ResonanceEnergy` | 把能量做成可插拔消耗项（复用 `UHodgeAbilityCost` 体系） |
| `UHodgeHavocSet` / `UHodgeHavocRules` | 暗流燃料（DarkFlow）与规则 |
| `UHodgeAnimNotify_DarkSurgeCommit` | 暗涌提交动作（通知驱动，非时间轴） |
| `UHodgeAnimNotifyState_CinematicCamera` | 共鸣解放前半段的电影镜头窗口；配合 `HodgeCinematicCameraProfile/Shots`、`UHodgeHeroComponent::RefreshCinematicCamera()`、`UHodgeCameraMode_Cinematic` |
| `UHodgeResonanceEnergyWidget` / `UHodgeAbilityIconWidget` | 能量环与技能图标；数据经 `UHodgeGameplayUIDataSource.GetResonance()` |

玩法配置（`Docs/Guides/resonance-*.md`）：E 键共鸣技能（8 秒 CD）、R 键共鸣解放（满充消耗、12 秒 CD、阶段回能、右下充能 HUD、前半段电影镜头、全程翼 + 金刚体固定 Box 命中）、暗涌的灭音 / 强化五段 / 破命共享 E 冷却 / 20% 湮灭增伤。
