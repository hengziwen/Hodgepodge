## 开发流程

1. 先读取目标资源、源文件与导入设置，明确 FBX/Interchange 和当前插件支持范围。
2. 按本机 5.5 AssetImportTask 设置导入路径、覆盖范围、骨架和材质选项，不沿用 5.8 默认管线。
3. 只写明确目标资产，重复运行支持读取已有结果并诊断部分失败；不覆盖无关用户调整。
4. 核对输出数量、资源类型、缩放、骨架和引用，再按需求执行编辑器视觉验证。
